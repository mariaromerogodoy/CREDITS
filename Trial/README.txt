IMAGE LINK GALLERY
==================

This folder contains 296 images from the uploaded ZIP and an index.html page.

HOW TO ADD A SOURCE LINK
1. Open index.html in a text editor.
2. Search for the image filename or the numbered HTML comment above it.
3. Replace href="#" with your source URL.

Example:
<a href="https://example.com/source" target="_blank" rel="noopener noreferrer">

You only need to change the href once for each image. The image and the caption are inside the same link.

If you want the visible caption to show the URL too, replace:
<figcaption>add source link</figcaption>
with:
<figcaption>https://example.com/source</figcaption>

No JavaScript or frameworks are used.
